How it works
  1. Transmit a 20 ms linear-FM chirp (2 kHz bandwidth) on a 6° rotating beam.
  2. Propagate using the sonar equation: spreading + absorption loss, target strength, beam pattern, Doppler, volume reverberation and ambient noise.
  3. Pulse-compress the echo with a Hann-weighted matched filter (0.4 m range resolution, ~15 dB gain).
  4. Detect with a cell-averaging CFAR that adapts the threshold to the local background.
  5. Track: cluster detections each scan, associate by nearest neighbour, smooth with an α-β filter, confirm after 4 hits.

The scan is time-compressed so the display stays lively; target motion runs in real time (× time scale).
